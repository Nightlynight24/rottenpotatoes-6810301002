## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | รวมชุดเครื่องมือสำหรับทดสอบ โดยดึง library มาให้|
| junit-jupiter | ใช้กำหนด test เช่น method ที่มี @test|
| assertj-core | ใช้ตรวจว่าผลจริงตรงกับที่คาดหวัง เช่น assertThat(...).isEqualTo(...) ที่เราใช้|
| mockito-core | ใช้จำลองส่วนที่โค้ดต้องเรียก เช่น บริการอื่น เพื่อทดสอบส่วนของเราแยกได้|

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
  - ถ้าเห็น green อย่างเดียวจะรู้ว่า test โค้ดปัจจุบันผ่าน แต่จะไม่รู้ว่าถ้ามีข้อผิดพลาด test โค้ดจะจับได้มั้ย ตัวอย่างเช่น test อาจจะไม่ได้ตรวจคำตอบเลยก็ได้ ตอนโปรแกรมคืนคำตอบผิดแล้ว test ล้ม บอกอะไรเกี่ยวกับความสามารถของ test

2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
  - ใช้คำสั่ง git clone repository ที่ใช้ทำงานลงมาที่เครื่องใหม่อีกครั้ง จากนั้นก็พร้อมทำงานต่อได้เลย แต่ก่อนเครื่องหาย ต้อง commit และ push งานขึ้น GitHub ไว้ก่อน จึงจะดึงกลับมาได้เท่านั้น
